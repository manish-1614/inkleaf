# Phase 2 Plan 01 — Architecture Refactor: ViewModel & Single-Pass Data Flow

<objective>
Restructure Inkleaf's reader data flow so a `ReaderViewModel` owns document loading and UI state, each document open performs exactly ONE SAF stream read (streaming SHA-256 fingerprint computed during that single pass), parsed blocks are cached by fingerprint (LRU cap 2), and raw markdown is released after parsing — eliminating today's 4x-read-per-open waste and rotation-triggered full reload churn.

Purpose: ROADMAP Phase 2 requirements PERF-03 (eliminate redundant reads), PERF-04 (config-change/process-death survival), PERF-05 (parse-once caching + memory diet).
Output: Refactored repository, new ViewModel layer, slimmed MainActivity/ReaderScreen; `gradlew compileDebugKotlin` green.
</objective>

<must_haves>
Goal-backward truths mapped to ROADMAP Phase 2 success criteria:

1. **Single SAF stream read per open action** (criterion #1) — `SafDocumentRepository.openDocument()` is the ONLY function in the codebase that calls `openInputStream`; MainActivity's two former full-read calls (MainActivity.kt:40, :68) become either `vm.openDocument(uri)` or cursor-only `getDocumentInfo`; ReaderScreen's `loadData()` (ReaderScreen.kt:60-74) is deleted.
2. **Rotation/process-death survival** (criterion #2) — ViewModel is activity-scoped via `viewModel(factory = Factory)`; rotation keeps the same VM instance → no reload. Process death: `SavedStateHandle["document_uri"]` restores the URI string and triggers one fresh load (content itself is not persisted; a re-read after process death is expected and acceptable).
3. **Warm-cache reopen skips re-parse** (criterion #3) — in-ViewModel `LinkedHashMap` LRU keyed by fingerprint, cap 2 entries, access-order eviction. On cache hit: emit cached blocks immediately, skip `parseToBlocks`. The file IS still read once to learn its current fingerprint — allowed; criterion governs parsing.
4. **No raw markdown retained** (criterion #4) — `UiState.Ready` holds `(DocumentMetadata, List<BlockModel>)` only; `LoadedDocument.content` is used solely as the `parseToBlocks` argument inside the load coroutine and never assigned to any field/state property. Verified by grep inspection.
5. **Behavior preserved** (criterion #5) — TOC drawer, search (match cycling), theme switching, scroll restore (via `pendingScrollIndex` consume pattern), scroll save (400 ms debounce relocated to VM), refresh button, error Retry, safe `scrollToBlockIndex` helper (Phase 1 fix — STAYS verbatim in ReaderScreen).
6. **Compile gate** — `cmd /c "gradlew.bat compileDebugKotlin --console=plain"` passes.
</must_haves>
